# Narendra Shiwale - Mimicry Artist Website

Official portfolio and booking web application for Narendra Shiwale, featuring interactive voice samples, character showcase, video gallery, and direct event booking forms.

## Features
- **Theatrical UI Design**: Dark gold-accented layout with modern typography.
- **Voice Soundboard**: Interactive audio player with waveform visuals.
- **Mimicry Quiz**: Test your knowledge on famous vocal performances.
- **Event Booking System**: Detailed inquiry form with direct estimation logic.
- **Responsive Media Gallery**: Video highlights and image showcases.

## How to Run
Open `index.html` in any web browser to view the portfolio.
